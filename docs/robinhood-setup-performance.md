# Robinhood transport setup reuse

A manual quote request previously performed MCP initialize, initialized notification and tool discovery before every tools/call. The Worker can now reuse negotiated setup for the same authorization-token fingerprint and exact required tool set for up to five minutes, with a 15-second safety margin before authorization expiry. The in-memory cache has at most 32 entries, evicts old entries and does not persist across Worker restarts. Providers that do not return a session ID retain the original per-request setup.

Only the session ID is cached, indexed by a SHA-256 token fingerprint and required tool names. Access checks, encrypted connection reads, authorization expiry and origin checks still run on every private request. Tokens, quotes, metadata, account data and holdings are not cached by this optimization. Disconnect invalidates the corresponding negotiated sessions. An upstream call failure evicts its setup; the next manual request initializes normally. There is no background polling or automatic repeat quote call.

Every refresh still calls the provider for the requested quotes. Provider timestamps and receipt clocks retain their original meaning and are not rewritten. setup_reused is a strict optional boolean in exported request timing; old exports lack this field and remain unknown. setup_ms, quote_ms, worker_ms and browser_ms retain their definitions. A warm Worker can avoid three negotiation requests, but a different Worker instance or an expired session can still require setup.

Tests compare cold and warm authenticated paths with a synthetic provider, verify failure eviction and disconnect refusal, and exercise cache expiry, token/tool partitioning and capacity limits. Synthetic timing proves removal of setup work only. Actual provider freshness and user-facing improvement require a new owner-operated quote export, compared with the prior session. No exchange-latency claim, freshness threshold change, Greeks verification, scanner-ranking change or trading action is made.
